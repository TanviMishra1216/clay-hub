# Clay Club Learning Hub

A beginner-friendly educational website for my high school's Clay Club.

The goal of this project is to help current and future students learn clay techniques, understand glazing and firing, find project inspiration, and access club resources in one organized place.

## Project Goals

- Build a polished educational website
- Learn professional software engineering practices
- Practice Git and GitHub
- Design before coding
- Create a project that can grow over time

## Version 1 Scope

Version 1 will focus on structure, navigation, and beginner-friendly content.

Possible pages:
- Home
- Getting Started
- Techniques
- Glazing & Firing
- Project Ideas
- FAQ
- Gallery
