# Homepage Wireframe — Clay Club Learning Hub

## Purpose of the Homepage

The homepage should quickly explain what the Clay Club Learning Hub is and help students find the right starting point.

The homepage is not meant to contain everything. It should act like a friendly front door.

---

## Homepage Layout

### 1. Header / Navigation

Content:
- Site name: Clay Club Learning Hub
- Navigation links:
  - Home
  - Getting Started
  - Techniques
  - Glazing & Firing
  - Project Ideas
  - FAQ

Purpose:
Help users move around the site easily.

---

### 2. Hero Section

Content:
- Main heading: Learn, Build, Glaze, Create
- Short description:
  A beginner-friendly resource hub for Clay Club students to learn techniques, understand the clay process, and find project inspiration.
- Main button: Start Here
- Secondary button: Browse Project Ideas

Purpose:
Immediately explain what the site is and guide beginners.

---

### 3. Beginner Starting Point

Content:
- Heading: New to Clay Club?
- Short explanation:
  Start with the basics: how clay works, what to expect, and how to begin your first project.
- Link to Getting Started page

Purpose:
Make the site welcoming for beginners.

---

### 4. Resource Cards

Content:
Three or four cards linking to major sections:

Card 1:
- Title: Techniques
- Description: Learn hand-building skills like pinch pots, coils, slabs, scoring, and slipping.

Card 2:
- Title: Glazing & Firing
- Description: Understand drying, glazing, kiln safety, and finishing your piece.

Card 3:
- Title: Project Ideas
- Description: Find inspiration for beginner, functional, decorative, and challenge projects.

Card 4:
- Title: FAQ
- Description: Get answers to common Clay Club questions.

Purpose:
Give users clear paths into the site.

---

### 5. Featured Tip or Reminder

Content:
- Example tip:
  Always score and slip before attaching two clay pieces together.

Purpose:
Make the homepage useful even if students only glance at it.

---

### 6. Footer

Content:
- Clay Club Learning Hub
- Made for future Clay Club students
- Optional: school/club note

Purpose:
Give the site a simple ending and make it feel complete.
