# Site Map — Clay Club Learning Hub

## Purpose

This document defines the main pages of the Clay Club Learning Hub and explains what each page is responsible for.

A good site map helps prevent the website from becoming confusing as more content is added over time.

---

## Main Navigation

The Version 1 navigation will include:

- Home
- Getting Started
- Techniques
- Glazing & Firing
- Project Ideas
- FAQ

The Gallery page may be added later after photos and teacher approval are available.

---

## Page Responsibilities

### Home

Purpose:
Introduce the Clay Club Learning Hub and guide students to the most useful sections.

Possible sections:
- Welcome message
- What this site helps with
- Beginner starting point
- Featured technique or project idea
- Links to major resource sections

---

### Getting Started

Purpose:
Help new students understand the basics of Clay Club.

Possible sections:
- What Clay Club is
- What beginners should know
- Basic clay process
- Common beginner mistakes
- What to ask the teacher before starting

---

### Techniques

Purpose:
Teach common clay-building techniques.

Possible sections:
- Pinch pots
- Coil building
- Slab building
- Scoring and slipping
- Smoothing
- Attaching pieces
- Carving and texture

---

### Glazing & Firing

Purpose:
Explain the clay finishing process.

Possible sections:
- What glazing is
- How many coats to use
- What not to glaze
- Drying stages
- What firing does
- Common kiln safety reminders

---

### Project Ideas

Purpose:
Give students inspiration for what to make.

Possible sections:
- Beginner projects
- Functional pieces
- Decorative pieces
- Seasonal projects
- Challenge projects

---

### FAQ

Purpose:
Answer repeated student questions.

Possible questions:
- Can beginners join?
- What if my piece cracks?
- How long does firing take?
- Can I take my project home the same day?
- What if I miss a meeting?
- What should I do if I do not know what to make?

---

Home
