# Product Discovery — Clay Club Learning Hub

## Project Purpose

The Clay Club Learning Hub is a beginner-friendly educational website for my high school's Clay Club. It will help students learn techniques, understand the clay process, find project inspiration, and access useful club resources.

## Target Users

### Primary Users
- New Clay Club students
- Current Clay Club members

### Secondary Users
- Club teacher/advisor
- Future club leaders
- Students looking for project inspiration

## Problems This Website Solves

- Clay Club knowledge is scattered or only explained in person.
- New students may not know where to start.
- Students may forget important process steps like drying, glazing, and firing.
- Future club leaders need an organized place to preserve resources.
- The teacher may have to answer the same beginner questions repeatedly.

## Version 1 Goal

Version 1 should create a clear, organized, beginner-friendly website structure.

The goal is not to include every resource immediately.

The goal is to build a strong foundation that can grow over time.

## Possible Version 1 Pages

- Home
- Getting Started
- Techniques
- Glazing & Firing
- Project Ideas
- FAQ
- Gallery

## Version 2 Ideas

- Announcements
- Student gallery submissions
- Embedded videos
- Teacher resources
- Search
- Project filters
- Downloadable guides
- Club calendar

## Open Questions

2. What content already exists?

4. Should the tone feel formal, creative, or student-made?
